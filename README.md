# Vases communicants de l'habitation

Infographie interactive qui explique, en un coup d'œil, comment le manque de logements pousse des gens vers la rue au Québec.

**Le principe** : les logements sont reliés comme des vases. L'eau représente les ménages; le vase, les logements. Quand un vase est plein, les ménages débordent dans le suivant. Le dernier, c'est la rue.

**Trois actions sur le schéma** :
1. **Construire** pour agrandir les vases (plus de place, moins de débordement);
2. **Prévenir les expulsions** avant le débordement;
3. **Reloger tout de suite** (Logement d'abord), mais seulement s'il reste des logements libres.

Sous le schéma, les solutions sont classées en trois colonnes : *ça marche*, *ça marche à moitié*, *ça ne règle pas le problème*. Les étoiles (★ à ★★★) indiquent à quel point chaque constat est prouvé.

Un clic sur un vase, une flèche ou une solution ouvre une fiche : l'idée en clair, les chiffres du Québec, ce que montrent les études (avec leurs références) et les sources.

Ouvrir `index.html` dans un navigateur. Aucune dépendance locale (police Google chargée en ligne, avec repli système).

Sources : études publiées (citées dans chaque fiche) et données publiques (SCHL, ISQ, MSSS, Statistique Canada, SHQ, APCIQ).
