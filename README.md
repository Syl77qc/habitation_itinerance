# Vases communicants de l'habitation

Infographie interactive : cinq réservoirs (offre neuve, locatif privé, propriété, parc hors marché, itinérance), les flux entre eux tels que documentés par la littérature scientifique, et les leviers publics (« robinets »).

- L'épaisseur d'un tuyau indique la force de la preuve, pas la taille du flux.
- Les robinets en orange « fuient » : une partie de ce qu'on y verse n'atteint pas le réservoir visé.
- La ligne pointillée grise (propriété → locatif) est une relation souvent affirmée mais sans étude causale dans les études recensées.

Ouvrir `index.html` dans un navigateur. Aucune dépendance locale (polices Google chargées en ligne, avec repli système).

Sources : études publiées (citées dans chaque fiche) et données publiques (SCHL, ISQ, MSSS, Statistique Canada, SHQ).
